# PR #5 — OpenRouter: жанры и настроения

## Что реализовано

- Ручной запуск классификации **выбранных на странице** треков; за один запрос максимум 10 треков.
- OpenRouter Chat Completions API c `response_format: json_schema`, проверкой ответа, ID записей, структуры и количества меток. Модель задаётся в `.env`.
- Отправляются **только метаданные**: ID в SQLite, название, исполнитель, альбом и уже существующие жанры. Аудио, файловые пути и пользовательские секреты не отправляются.
- Результат сохраняется в `metadata_suggestions` с `provider=openrouter`, `genres`, `moods`, `model`, `status=pending`. **Реальные категории не меняются до принятия пользователем**.
- На главной странице выводятся предложения с кнопками «Принять»/«Отклонить». Подтверждение **добавляет**, но не удаляет существующие жанры и настроения.
- Повторный выбор уже обработанного трека не приводит к новому API-вызову и расходам. Отклонённые и принятые результаты также не отправляются повторно; опции `force` в PR нет.
- Отдельный журнал `ai_usage_logs`: модель, ID, токены и фактическая стоимость (когда OpenRouter предоставил `usage.cost`). Если сервис не возвращает стоимость, показывается «не предоставлена», а не оценка.
- Светлая тема, Tailwind CSS и локальные компоненты shadcn-vue сохранены.

## Настройка

После переключения на ветку:

```bash
php artisan migrate
php artisan optimize:clear
php artisan test --filter=OpenRouterClassificationTest
npm run build
```

Добавьте в локальный `.env` **без коммита секретов**:

```dotenv
OPENROUTER_API_KEY=ваш_ключ
OPENROUTER_MODEL=openai/gpt-4o-mini
```

Модель — лишь стартовый пример. Выбирайте модель OpenRouter, которая поддерживает структурированные ответы JSON Schema; проверьте её текущую цену на странице модели.

После изменения `.env` выполните `php artisan config:clear`.

## Ручная проверка

1. Запустите приложение как обычно, выделите **1–3 известных трека** с корректными артистами и названиями.
2. Нажмите **AI: классифицировать**. Это платный запрос, выполняйте его только если согласны на передачу метаданных и расходы. В OpenRouter будут отправлены очищенные *для поиска* названия (без повторного имени исполнителя и типичных пометок Official Music Video); исходные данные в SQLite останутся прежними.
3. Убедитесь, что появились предложения жанров и настроений под треками, но активные теги **не изменились**.
4. Одно предложение примите, другое отклоните: первый трек получит дополнительные теги, второй останется прежним.
5. Выделите уже классифицированный трек и повторите: должно появиться сообщение об отсутствии новых запросов.
6. Для трека с пустым ожидающим предложением выделите его и нажмите **«Повторить пустые AI-предложения»**. Для непустых или уже принятых/отклонённых предложений повтора не должно быть. Это отдельный платный вызов, инициируемый пользователем.
7. Проверьте, что основной поиск, URL-фильтры, ручное редактирование, создание категорий, массовое назначение и светлая тема продолжают работать.

## Известные ограничения

- Это классификация **по метаданным**, а не прослушивание аудио. Нейросеть может ошибиться или не узнать композицию.
- При смешанном выборе уже проверенные треки пропускаются. Отдельная кнопка **«Повторить пустые AI-предложения»** позволяет повторно отправить только записи с пустыми жанрами **и** настроениями и статусом `pending`. Это новый платный запрос. Непустые, принятые и отклонённые предложения не перезаписываются.
- Предложения хранятся по одному на трек и провайдера; решение принимается **для набора тегов целиком**, не по отдельной метке. После принятия лишние теги можно убрать вручную.
- Нет фоновой очереди, больших батчей и перезапуска задач. Запрос выполняется синхронно и может занимать до 90 секунд.
- Сведения об использовании токенов и стоимости зависят от модели и ответа API. Не предполагается, что каждое поле `usage` будет заполнено.
- При невалидном ответе модели категории не сохраняются. После такой ошибки запрос можно повторить; первый вызов при этом уже мог быть платным.
- Сервис предназначен для **локального использования**, без публикации API наружу без аутентификации.

## Реальная проверка (первые результаты)

- `AURORA — AURORA - The Seed`: пустые жанры и moods.
- `Adele — Adele - Rolling in the Deep (Official Music Video)`: пустые жанры и moods.
- `Avril Lavigne — Avril Lavigne - Girlfriend (Official Video)`: получены `Pop`, `Rock`, `Energetic`, `Fun`.

Это указывает на неоднородность качества классификации по метаданным. Добавлен `TrackLookupMetadata` для очистки данных, отправляемых модели, и безопасный повтор только пустых предложений. **Наличие категорий после повтора не гарантируется**, если модель не знает композицию; при необходимости можно затем протестировать более сильную модель через `OPENROUTER_MODEL` (изменение `.env` + `php artisan config:clear`). Не отправлять сразу всю коллекцию до оценки качества и расходов.
