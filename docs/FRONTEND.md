# Vue-интерфейс

Интерфейс влит в `main` (PR #3, merge commit `32ccec9`).

## Зафиксированные требования

- **Vue 3** и **Tailwind CSS v4**.
- **shadcn-vue** в режиме локальных компонентов: код компонентов находится в `resources/js/components/ui/`, приложение не импортирует виджеты из внешнего hosted UI. Файл `components.json` и алиас `@/` позволяют позднее применять `npx shadcn-vue@latest add ...`. В текущем PR локальные реализации Button/Input/Checkbox/Badge/Card находятся в репозитории.
- Иконки из официального пакета `@lucide/vue`.
- **Светлая тема по умолчанию**. Тёмная тема не реализована и не включается по системным настройкам. При будущей реализации пользовательский выбор темы нужно сохранять в `localStorage`.
- Жанры, настроения, поиск, режим «без категорий», страница пагинации отражаются в query string. Должны работать прямое открытие ссылки, перезагрузка и кнопки назад/вперёд.

## Архитектура

Laravel обслуживает страницу `GET /` с Vue mount-point и JSON-каталог `GET /catalog`. Для мутаций используются защищённые CSRF POST/PUT endpoints.

Пример ссылки:
```
/?genres%5B%5D=1&genres%5B%5D=2&moods%5B%5D=5&search=night&page=2
```
Приложение читает query при открытии и `popstate`, обновляет адрес с History API. Обычный HTTP запрос к `/catalog` получает те же параметры, что в пользовательском URL.

Сервер фильтрует по правилу OR внутри группы жанров, OR внутри группы настроений и AND между группами.

Массовое добавление/удаление одного выбранного тега применяет его только к выделенным строкам **текущей страницы**. Максимум 200 IDs на запрос. Редактирование одного трека может полностью заменить его категории.

## Локальная проверка

```bash
npm install
npm run build
php artisan optimize:clear
php artisan test
php artisan serve
```

`package-lock.json` зафиксирован в репозитории — при изменении зависимостей обновляйте его вместе с `package.json`.

Откройте локальное приложение, отметьте пару жанров и настроение, скопируйте URL и откройте его в новом окне. Убедитесь, что фильтры восстановились. Попробуйте поиск, переключение страницы, выбор неразмеченных треков, создание категории и массовое добавление/удаление.

Если `npm run build` показывает ошибки несовместимости зависимостей, пришлите полный вывод.

## Ограничения

- Приложение остаётся локальным, без Docker.
- Изменения в API чтения/редактирования рассчитаны на один локальный пользовательский сеанс; внешняя публикация в интернет без аутентификации не поддерживается.
- Переименование/слияние категорий и экспорт выделенных треков не входят в текущий интерфейс.
- Фильтры не сохраняются в localStorage: авторитетный источник **URL**, как и требовалось.
- Повторный импорт файла пока может вернуть вручную удалённый автоматически импортированный жанр: отдельное решение понадобится для устойчивых отклонений от автоматических рекомендаций.
