# AI Classification — состояние PR #5

**Статус:** черновик для локального тестирования, не merged.

Контракт: самостоятельный Laravel/Vue, SQLite, OpenRouter API по явному действию, никаких файлов с музыкой и Python в контейнере.

### Модель данных

Миграция добавляет `moods` и `model` к таблице `metadata_suggestions` и таблицу `ai_usage_logs` для ответа API по токенам и стоимости.

### API

- `POST /ai/classify`, JSON `{"tracks":[1,2,3]}`; максимум 10 записей. Для уже обработанных записей повторный запрос OpenRouter не делается.
- `PUT /ai/suggestions/{id}`, JSON `{"decision":"accept"}` или `{"decision":"reject"}`. Можно обработать только pending OpenRouter-предложения; защита от повторного подтверждения.
- `GET /api/tracks` дополнительно включает `metadata_suggestions` типа OpenRouter для вывода в интерфейсе.

### Ручной приоритет

Принятие AI-предложения добавляет новые теги, не меняя существующие. Отклонение не затрагивает теги. После принятия/отклонения не предусмотрена автоматическая перезапись AI-результатов.
