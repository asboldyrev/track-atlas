# PR #4 — предложения жанров из MusicBrainz

Этот этап **не изменяет назначенные трекам категории**. Он находит возможное соответствие в базе MusicBrainz и сохраняет предложенные жанры отдельно — для будущего просмотра и подтверждения в интерфейсе.

## Настройка

В локальном приложении Docker не требуется. Примените миграции:

```bash
php artisan migrate
php artisan test --filter=MusicBrainzEnrichmentTest
```

## Пробная обработка

Для тестирования только нескольких композиций, у которых есть исполнитель и название:

```bash
php artisan music:enrich --limit=5
```

Для одной конкретной записи, если известен ID трека:

```bash
php artisan music:enrich --track=123
```

Повторная проверка ранее обработанных:

```bash
php artisan music:enrich --track=123 --force
```

**Никакой массовой автоматической обработки**: команда запускается вручную, по умолчанию выбирает только первые 10 ещё не проверенных треков, `--limit` ограничен 1–30. Результаты сохраняются в `metadata_suggestions` (provider, recording_mbid, match_score, genres, status). Категории `track_tag` не меняются. При ручном редактировании ничего не пропадает.

## Сопоставление

1. Поиск записи MusicBrainz по названию и исполнителю.
2. Берётся только результат со score не меньше 90 и точным совпадением названия и artist credit после нормализации регистра и пробелов. Это намеренно строгая проверка: некоторые реальные релизы могут быть пропущены, зато риск приписать жанры другому треку ниже.
3. По MusicBrainz recording MBID читаются **genres**; учитываются жанры с положительным счётчиком.
4. Если подходящего соответствия нет или жанров у recording нет, сохраняется пустой результат. Повторять обработку без `--force` не нужно.

Из-за строгого совпадения в некоторых случаях featuring-исполнители и разные версии написания могут не определяться. Позже можно добавить проверки альбома, длительности и другие источники жанров.

## Ограничения и безопасность

- Название и исполнитель передаются в публичный API MusicBrainz **только по явной команде**.
- Нужен интернет. По правилам MusicBrainz используется осмысленный User-Agent и интервал не менее 1.2 секунды между HTTP-запросами.
- При HTTP-ошибке запись не сохраняется как обработанная, чтобы её можно было повторить.
- Нет вызовов OpenRouter, отправки аудио и автоматического принятия результатов.
- Для продакшена или коммерческого использования нужно отдельно ознакомиться с условиями API MusicBrainz.

Источник: https://musicbrainz.org/doc/MusicBrainz_API и https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting .
