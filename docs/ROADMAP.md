# План реализации

## Phase 1 — каталог без AI (MVP)
- [ ] Проверить существующий Laravel-каркас и установить Vue 3 (при необходимости Inertia).
- [ ] Подключить SQLite и конфигурацию музыкальной папки.
- [ ] Создать tracks/tags/track_tag с миграциями.
- [ ] Сканер папки Artisan + metadata reader + имя файла как fallback.
- [ ] Повторное сканирование, missing-status, отчёт об ошибках.
- [ ] Список треков, поиск, пагинация.
- [ ] Фильтры-чекбоксы genre и mood, OR внутри / AND между.
- [ ] Редактирование тегов, массовая разметка, поиск неразмеченных.
- [ ] Feature-тесты поведения сканера, фильтра и защиты ручной разметки.

**Готово, когда:** по существующей локальной библиотеке можно находить референсы по одному/двум типам фильтров без интернета и Docker.

## Phase 2 — метаданные и AI-помощник
- [ ] Определить справочник тегов, правила нормализации и алиасы.
- [ ] OpenRouter provider: модель из конфигурации, структурированный ответ, retry/rate-limit.
- [ ] Preview/approve/reject AI-предложений, источник и защита ручного выбора.
- [ ] Контроль расходов, батчи и повторные запуски с кешированием.
- [ ] Опционально Perplexity Sonar/веб-поиск для неизвестных записей.
- [ ] Тесты на неверный JSON, ошибки сети и конфликт с ручными тегами.

**Готово, когда:** можно выбрать треки без mood, получить предложения, проверить их и применить без потери собственных назначений.

## Phase 3 — анализ звука (только если нужен)
- [ ] Измерить качество текстовой классификации: есть ли реальная потребность в аудио?
- [ ] Выбрать Essentia и совместимые модели, проверить лицензии и платформенные требования.
- [ ] Подготовить одноразовый Docker-образ с Python; веб-приложение остаётся вне контейнера.
- [ ] Передавать только выбранные локальные файлы read-only, получать JSON.
- [ ] Сравнить результаты с ручными категориями; не перезаписывать их.

**Не делать заранее:** сложные очереди, отдельную БД, автоматическую обработку всей медиатеки дорогими сервисами, встроенный плеер.

## Порядок приоритетов
Надёжный офлайн-каталог → быстрое ручное присвоение тегов → доступная AI-помощь → экспериментальный анализ аудио. Временные оценки из обсуждения были приблизительными, не сроками обязательства.
