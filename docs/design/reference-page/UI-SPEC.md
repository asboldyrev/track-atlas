## 1. Состав страницы

Клиентское видение: **одна колонка, ровно три блока, без сайдбара, без лишних кнопок и текста.**

| Решение | Обоснование |
| --- | --- |
| Одна колонка: **Жанры → Настроения → Треки** | Заданный порядок; фильтры всегда выше результата. |
| Сайдбар удалён | Требование заказчика. |
| Удалены: поиск, «Полнота разметки», чипы активных фильтров, «Сбросить» в шапке, сортировка/направление/размер страницы, плотность, копирование ссылки, выбор строк, массовые действия, редактор тегов | «Без дополнительных кнопок и текста»; всё это осталось на `/tagging`. |
| Пагинация сохранена («страница 1 из 48», «Назад»/«Вперёд») | 1 435 треков; это часть блока «Треки», а не отдельная кнопка. |
| Шапка приложения: «Track Atlas» + три текстовые ссылки | Каркас приложения, не контент страницы. Иконки, подзаголовок и бейдж «Локальная библиотека» убраны. |
| Действия только в состояниях: «Сбросить фильтры» (пустой результат), «Повторить» (ошибка) | Иначе пользователь застревает. В рабочем состоянии кнопок нет. |
| Счётчика «найдено N» нет | В спеке он не предусмотрен; единственный текст — подписи и состояния. |

## 2. Схема экрана

### 2.1. Десктоп, ≥ 768 px

```
┌──────────────────────────────────────────────────────────────────┐ 1280 px
│  Track Atlas                    Референсы  Категории  Разметка    │ шапка h=56, border-b
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ Жанры                                          [ ИЛИ | И ] │  │ ← Card 720×, p=20, r=12
│  │                                                            │  │
│  │ ☐ animated              ☐ Классическая музыка (classical) │  │   чекбоксы в 2 колонки,
│  │ ☐ ambientgenre          ☐ Джаз (jazz)                      │  │   строки 26 px, gap 24/2,
│  │ ☐ Кантри (country)      ☐ Диско (disco)                    │  │   область 224 px,
│  │ ☐ …                     ☐ …                                │  │   внутренняя прокрутка
│  └────────────────────────────────────────────────────────────┘  │
│                          ↕ 20 px                                 │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ Настроения                                     [ ИЛИ | И ] │  │
│  │ ☐ Беззаботный (Lighthearted)   ☐ Безмятежный (Serene)      │  │
│  └────────────────────────────────────────────────────────────┘  │
│                          ↕ 20 px                                 │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ Треки                                                      │  │
│  │ Anthem For The Underdog                                    │  │
│  │ [Рок] [postpunk] [Бунтарский] [Дерзкий]                    │  │
│  │ ────────────────────────────────────────────────────────── │  │
│  │ Could You                                                  │  │
│  │ [Метал] [Индастриал] [Угрюмый] [Злой]                      │  │
│  │ …                                                          │  │
│  │ страница 1 из 48                            [Назад] [Вперёд]│  │
│  └────────────────────────────────────────────────────────────┘  │
│  ← 720 px →                                                      │
└──────────────────────────────────────────────────────────────────┘
```

- Колонка контента: **720 px**, центрирована. Оболочка страницы `/` сужается до 768 px (720 + 2×24), чтобы шапка и колонка стояли на одной сетке. На `/categories` и `/tagging` ширина оболочки не меняется.
- Отступы: 40 px сверху, 64 px снизу, 20 px между блоками.
- Карточка: `bg-card`, `border 1px var(--border)`, `radius 12`, `shadow-sm`, padding 20 px (`ui/card` уже такой).

> Отклонение от `REFERENCE_PAGE_SPEC.md` §2: там колонка «до 720 px по левому краю». Макет центрирует 720 px: критерий приёмки требует только «не шире 720 px», а при левом крае на 1440 px справа остаётся ~600 px пустоты. Если нужен именно левый край — снимается `mx-auto`, остальное не меняется.

### 2.2. Мобильный, < 640 px

- Колонка на всю ширину, padding 16 px, верх 24 px, низ 48 px, между блоками 16 px.
- Чекбоксы — **в одну колонку**, высота области 224 px (7 строк по 32 px).
- Заголовок блока и переключатель остаются в одной строке.
- Треки: название переносится, теги переносятся.
- Пагинация: текст слева, кнопки справа.

### 2.3. Узкий экран < 360 px

Шапка переносится на две строки (бренд, под ним ссылки), высота 66 px. Контент не меняется; горизонтальной прокрутки нет (проверено: `scrollWidth = 320` на ширине 320).

## 5. Блок «Жанры» / «Настроения»

### 5.1. Анатомия

```
Card  p-4 sm:p-5
├─ header  flex items-center justify-between gap-3  min-h-7  mb-3
│  ├─ h2 «Жанры» (text-sm font-semibold)
│  └─ ModeToggle «ИЛИ | И»
└─ список  grid grid-cols-2 gap-x-6 gap-y-0.5
           max-h-56 overflow-y-auto pr-1
   └─ строка: ☐ + подпись (min-h-[26px])
```

- `<section aria-labelledby>`, заголовок `h2`, список — `role="group"` с тем же `aria-labelledby`.
- Переключатель справа в шапке, вертикально центрирован.
- Область списка: 224 px, внутренняя прокрутка, тонкий скроллбар `--border`. Страница не растягивается на 60 жанров.
- **Две колонки** на ширине ≥ 640 px: при 720 px видно 16 значений вместо 8 — так 60 жанров листаются вчетверо быстрее. Порядок остаётся алфавитным, строка за строкой (слева направо). На мобильном — одна колонка.
- В макете 28 жанров и 16 настроений — срез реального справочника (в проекте ~60 и ~37), не полный список.

### 5.2. Строка значения

Нативный чекбокс, визуально стилизованный; вся строка — `<label>`.

| Свойство | Значение |
| --- | --- |
| Высота строки | min 26 px (моб. 32 px) |
| Отступы | 1 px 6 px, отрицательный левый margin −6 px (выравнивание текста по краю карточки) |
| Галочка | 16×16, радиус 4, рамка 1 px `--primary`; выбранная — заливка primary, белая галочка 10 px |
| Зазор | 8 px между чекбоксом и подписью |
| Текст | 13/16; выбранный — 500 |
| Hover | фон `--accent`, радиус 6 |
| Фокус | ring 2 px `--ring`, offset 2 px вокруг квадрата чекбокса |
| Длинная подпись | переносится, `overflow-wrap: anywhere`, без обрезки |

Состояния:

| Состояние | Чекбокс | Подпись | Фон строки |
| --- | --- | --- | --- |
| Не выбран | пустой квадрат, рамка primary | foreground, 400 | прозрачный |
| Не выбран, hover | без изменений | foreground | accent |
| Не выбран, focus-visible | кольцо ring | foreground | прозрачный |
| Выбран | заливка primary + галочка | foreground, 500 | прозрачный |
| Выбран, hover | без изменений | foreground, 500 | accent |
| Выбран, focus-visible | кольцо ring | foreground, 500 | прозрачный |

Клик по строке или пробел на чекбоксе переключает значение. Дубликатов нет. Снятие последнего значения возвращает группу в состояние «не фильтрует», режим при этом сохраняется.

Доступное имя элемента — его подпись (`Поп (pop)`), тип задаётся группой («Жанры»), поэтому `sr-only`-префиксы не нужны. Скринридер произносит «Поп (pop), флажок, не отмечен».

### 5.3. Переключатель «ИЛИ / И»

Расположение: шапка блока, справа от заголовка. Отдельный для каждого блока.

| Свойство | Значение |
| --- | --- |
| Контейнер | 2 px padding, фон `--secondary`, радиус 8, высота 28 |
| Сегмент | min-width 44, высота 24, padding 0 8, радиус 6, шрифт 12/16, 500 |
| Порядок | **«ИЛИ», затем «И»**; «ИЛИ» выбрано по умолчанию |
| Активный | фон card, текст foreground, `shadow-sm` |
| Неактивный | прозрачный, текст muted; hover — текст foreground |
| Фокус | ring 2 px `--ring` вокруг текста сегмента (offset 3) |
| Ширина группы | 92 px (2 × 44 + 2 × 2) |
| Недоступен | opacity .5, `cursor: not-allowed`, `disabled` на обоих radio |

Значения режимов и их смысл — `REFERENCE_PAGE_SPEC.md` §3.2: «ИЛИ» — хотя бы одно выбранное значение, «И» — все выбранные; между блоками всегда «И»; пустая группа не фильтрует.

Состояния:

- **Обычное** — оба сегмента интерактивны.
- **Пока справочник грузится** (S1) и **при ошибке справочника** (S7) — переключатель виден, но недоступен (по спеке архитектора). Значение из URL сохраняется.
- **При 0 или 1 выбранном значении** — доступен, режим просто не влияет на результат; disabled не делаем (спека §3.2).
- Смена режима немедленно перезапрашивает список и сбрасывает страницу на 1.

A11y: `role="radiogroup"`, `aria-label` «Режим выбора жанров» / «Режим выбора настроений», нативные radio; выбранный — `checked`.

Параметры URL (по `REFERENCE_PAGE_SPEC.md` §8.1): `genres_mode`, `moods_mode` = `and|or`, по умолчанию `or` и в адрес не пишется.

## 6. Блок «Треки»

### 6.1. Заголовок

Только `h2` «Треки». Счётчика количества нет — спеку это не предусматривает, а результат виден по списку и пагинации. (Если заказчик захочет счётчик, он добавляется в `h2` как muted-число, место есть.)

### 6.2. Строка трека

```
<li>                              padding 14px 0; border-bottom 1px
  <h3>Anthem For The Underdog</h3>  14/20, 600, переносится целиком
  <div>                              margin-top 6px; flex wrap; gap 6px
    [жанр] [жанр] [настроение] [настроение]
  </div>
</li>
```

- Только название, жанры и настроения. Исполнителя, альбома, длительности, пути и кнопок нет.
- Строка не кликабельна, hover-подсветки нет.
- Название **не обрезается**: переносится на сколько нужно строк, `overflow-wrap: anywhere`. `line-clamp` и `text-overflow` запрещены.
- Теги: сначала жанры (заливка secondary), затем настроения (рамка `--border`). Различие не только цветом: порядок фиксирован, тип передан `sr-only`-подписью «Жанр:» / «Настроение:».
- Нет тегов — строка содержит только название (без «Без категорий»).
- Разделитель — нижняя граница строки; у последней строки её нет.
- Первая строка начинается с 2 px, последняя заканчивается 2 px.

### 6.3. Пагинация

```
<div class="mt-3.5 flex items-center justify-between gap-3">
  <span class="text-[13px] text-muted-foreground tabular-nums">страница 1 из 48</span>
  <div class="flex gap-2">
    <button …>Назад</button>
    <button …>Вперёд</button>
  </div>
</div>
```

- Кнопки: высота 28 px, padding 0 10 px, рамка `--border`, радиус 8, текст 12/16 500. Hover — `--accent`. Disabled — opacity .4 (первая/последняя страница, идёт загрузка).
- Текст «страница N из M» — по спеке §7.2; `tabular-nums`, чтобы не дёргался.
- Блок пагинации скрыт, если страниц одна, при пустом результате и ошибках.
- `per_page=30` фиксирован; выбора размера нет.

## 7. Состояния экрана

| # | Состояние | Что видно | Текст |
| --- | --- | --- | --- |
| S1 | Первая загрузка | В блоках жанров/настроений — по три серые полоски (14 px, ширины 38/52/31 %); переключатели disabled. В треках — 3 скелетон-строки. Пагинации нет. `aria-busy="true"`. | sr-only «Загрузка жанров…», «Загрузка настроений…», «Загрузка треков…» |

| S3 | Есть результаты | Строки, пагинация (если страниц > 1). | — |
| S4 | Пусто после фильтров | Dashed-рамка, по центру сообщение и текстовая ссылка сброса. Выбранные значения и режимы остаются. Пагинации нет. | «Ничего не подходит под выбранные фильтры» + «Сбросить фильтры» |
| S5 | Пустой каталог | Та же рамка, одна строка, без действия. | «В каталоге пока нет треков» |
| S6 | Ошибка загрузки треков | Красная плашка вместо списка; старые строки скрыты; счётчика и пагинации нет. | «Не удалось загрузить треки» + «Повторить» |
| S7 | Ошибка загрузки справочника | В блоке вместо списка — компактная плашка; переключатель disabled. Другой блок и треки работают. | «Не удалось загрузить жанры» / «Не удалось загрузить настроения» + «Повторить» |
| S8 | Справочник пуст | Вместо списка одна muted-строка; переключатель скрыт (объединять нечего). | «Пока нет жанров» / «Пока нет настроений» |
| S9 | Одно значение в справочнике | Один чекбокс, переключатель скрыт | — |
| S10 | Долгая загрузка | Тот же скелетон, без спиннеров и таймеров | — |
| S11 | Значений больше, чем помещается | Внутренняя прокрутка области; страница не растягивается | — |

Правила:

- Ошибка и пустое состояние взаимоисключающи: при ошибке пустое состояние не показывается.
- «Повторить» перезапрашивает только упавшую часть, фильтры не сбрасывает.
- «Сбросить фильтры» снимает все значения обоих блоков и возвращает оба режима к «ИЛИ», страницу — на 1.
- Фокус при смене состояний не перемещается; ошибки объявляются `role="alert"`.
- Скелетоны статичны при `prefers-reduced-motion` (без пульсации), в обычном режиме — мягкая пульсация 2 s.

## 8. Адаптивность

| Диапазон | Колонка | Отступы | Список значений | Строка трека | Пагинация |
| --- | --- | --- | --- | --- | --- |
| ≥ 1024 | 720, центр | 40 / 24 / 64 | 2 колонки, 224 px | 14 px | текст слева, кнопки справа |
| 768–1023 | 720, центр | 40 / 24 / 64 | 2 колонки, 224 px | 14 px | то же |
| 640–767 | fluid (≤ 720) | 32 / 24 / 48 | 2 колонки, 224 px | 14 px | то же |
| 360–639 | fluid | 24 / 16 / 48 | 1 колонка, 224 px (7 строк) | 14 px | то же |
| 320–359 | fluid | 20 / 16 / 40 | 1 колонка, 224 px | 14 px | то же |

- Ни на одной ширине нет горизонтальной прокрутки: подписи переносятся, теги переносятся, название трека не обрезается.
- Шапка: ≥ 360 — одна строка; < 360 — две строки (66 px).
- Переключатель «ИЛИ/И» не переносится на отдельную строку: 92 px + заголовок помещаются в 320 px.
- 200 % zoom: раскладка переходит в мобильную, функции не теряются (WCAG 1.4.10 Reflow).
- Плотность строк на этой странице не переключается.

## 9. Клавиатура и взаимодействие

| Действие | Результат |
| --- | --- |
| Tab | «Перейти к содержимому» → ссылки шапки → переключатель жанров → чекбоксы жанров → переключатель настроений → чекбоксы настроений → «Назад» → «Вперёд» |
| Space на чекбоксе | переключить значение; список обновляется сразу |
| ← / → / ↑ / ↓ в группе «ИЛИ/И» | переключить режим (нативное поведение radio) |
| Клик по строке значения | переключить чекбокс |
| «Назад» браузера | восстановить фильтры, режимы, страницу |

- Радиогруппа в разметке стоит до чекбоксов, хотя визуально справа — так пользователь сначала выбирает режим, затем значения.
- Все элементы нативные (`input[type=checkbox]`, `input[type=radio]`, `button`); кастомных обработчиков клавиш нет.
- При обновлении списка фокус не теряется; `popstate` не перемещает фокус.
- Пока грузится, можно менять следующий фильтр: интерфейс не блокируется, побеждает последний запрос (на стороне кода).

## 10. Доступность

### 10.1. Семантика

- `<main id="main" tabindex="-1">` уже в оболочке; страница — три `<section aria-labelledby>`; `h1` «Track Atlas» в шапке, `h2` у блоков, `h3` у названий треков.
- Список треков — `<ul>/<li>`.
- Значения фильтров — нативные чекбоксы в `role="group"` с `aria-labelledby` заголовка блока; подпись = доступное имя.
- Режим — `role="radiogroup"` + `aria-label`; нативные radio, выбранный `checked`, недоступные — `disabled`.
- Ссылки шапки: `aria-current="page"` на активной.

### 10.2. Объявления

- Скрытый `role="status" aria-live="polite"` после загрузки/смены фильтра: «Найдено 42 трека» (склонение: 1 трек, 2–4 трека, 5+ треков, 11–14 треков). Только при изменении числа, не при каждом рендере.
- Ошибки — `role="alert"`; загрузка — `aria-busy="true"` и sr-only «Загрузка…».
- Пустой результат и пустой каталог дополнительно не announce-ятся (число 0 уже объявлено).

### 10.3. Контраст (измерено по токенам)

| Пара | Отношение | Норма |
| --- | --- | --- |
| foreground `#242523` на card `#ffffff` | 15.40:1 | AAA |
| muted `#706e66` на card | 5.11:1 | AA |
| muted на фоне `#faf9f6` | 4.85:1 | AA |
| белая галочка на primary `#343b35` | 11.52:1 | AAA |
| secondary-foreground на secondary (бейдж жанра) | 8.80:1 | AAA |
| ring `#7d8f78` на card | 3.46:1 | AA для нетекстовых |
| destructive на подложке ошибки | 4.84:1 | AA |

Рамка чекбокса — `--primary` (контраст 11.5:1), поэтому сам контрол различим без опоры на цвет текста. Границы карточек и разделители декоративны.

### 10.4. Прочее

- Зона нажатия: строка чекбокса 26 px на десктопе, 32 px на мобильном (WCAG 2.5.8 ≥ 24×24); кнопки пагинации 28 px.
- Никакой информации только цветом: выбранный чекбокс = заливка + галочка + `checked`; жанр/настроение = заливка/рамка + sr-only тип.
- Текст не в картинках, масштабируется; `lang="ru"`.
- `prefers-reduced-motion` отключает переходы и пульсацию.
- Тёмной темы нет, как и во всём проекте.

## 14. Отличия от `REFERENCE_PAGE_SPEC.md` и открытые вопросы

1. **Колонка центрирована, а не прижата влево** (720 px). Критерий спеки — «не шире 720 px»; центрирование убирает пустую полосу справа на широких экранах. Если нужен левый край — убрать `mx-auto`.
2. **Чекбоксы в две колонки на ≥ 640 px.** Спека требует чекбоксы и область 224 px; две колонки показывают 16 значений вместо 8 при том же порядке (алфавит, слева направо). Если нужна одна колонка — `grid-cols-1`, высота покажет 7 значений.
3. **Бейджи тегов в строке трека** (спека допускает «через запятую или чипы»).
4. **Счётчика результатов нет** — следует формулировке «единственный текст: подписи блоков, подписи элементов, состояния».
5. **Имена параметров** `genres_mode` / `moods_mode` — из спеки архитектора; если изменятся, поменяется только имя.
6. **Пагинация текстом** («страница N из M», «Назад»/«Вперёд») — спека допускает такой вид.
