# Track Atlas

**Track Atlas** — локальный каталог музыкальных референсов для создания новых композиций. Приложение индексирует существующую музыкальную библиотеку, позволяет размечать треки жанрами и настроениями (vibe) и находить подходящие примеры звучания.

> **Статус:** поэтапная разработка. Основа каталога и импорт метаданных реализованы; новый Vue-интерфейс находится в PR #3 и ожидает локальной проверки.

## Зачем нужен проект?

Когда появляется идея новой композиции, её предполагаемое звучание может быть известно лишь примерно — по жанру, настроению или их сочетанию. Track Atlas покажет список знакомых треков и исполнителей, которые можно использовать как референсы.

Это **не музыкальный плеер**, стриминговый сервис или инструмент редактирования аудиофайлов.

## MVP

- Рекурсивное сканирование папки с музыкой и чтение метаданных.
- Каталог названий, исполнителей, альбомов и категорий в SQLite.
- Фильтрация чекбоксами по нескольким жанрам и настроениям.
- Поиск по названию и исполнителю.
- Ручное и массовое назначение категорий.
- Повторное сканирование без потери пользовательской разметки.

## Технологии

- **Laravel + Vue 3** — приложение работает локально **без Docker**.
- **SQLite** — хранение каталога.
- **getID3** — кандидат для извлечения аудиотегов.
- **OpenRouter** — AI-классификация по названию/исполнителю.
- **Perplexity Sonar** — необязательный поиск сведений о редких композициях.
- **Docker + Python/Essentia** — только отдельный, необязательный будущий этап анализа аудио.

Коллекция преимущественно состоит из известных релизов, поэтому первый приоритет — метаданные и их классификация; сложное распознавание аудио отложено.
